# 暮行灯列 · Dusk Express

星夜里，一列亮着暖窗的慢车不断驶向新的地形：河谷、平原、丘陵、山岭、森林、湖泊、海滩与海洋随机接力，每次进入新区域都以转弯、穿隧道或到站停车中的一种方式过渡。铁路也随地形换姿：深谷与水面上是高耸的拱桥，平原、丘陵与森林里则落成贴地的路堤——地面隆起一道等高道床托着铁轨，桥与路堤在边界处由桥台衔接。可以远观整列火车压过拱桥或贴着草坡驶过，可以伴飞在车头旁，也可以坐进车厢，透过车窗看两岸灯火与映月的河流。

## 交互

- 拖动环视，双指（或滚轮）缩放；车厢模式下拖动是转头看窗外，缩放调整视野宽窄。
- 轻点车头鸣笛：一声汽笛伴着一团蒸汽从烟囱涌出。
- 底部「远景 / 伴飞 / 车厢」三个按钮切换机位；键盘 `1` / `2` / `3` 同样可切换。
- 底部环境栏：点天气按钮弹出菜单，在 晴朗 / 下雨 / 下雪 / 冰雹 / 雾天 / 绿叶 / 枫叶 之间直接选择（Esc 或点空白处关闭）；「清晨 / 正午 / 黄昏 / 深夜」四个时刻快捷片一键跳到对应时段；拖动时刻滑杆从早到晚细拨一天；「自动」开启后时间缓缓流转（约 4 分钟一天）、天气随机更替。手动操作会暂停自动，再点「自动」恢复。
- 天气切换有约 2.5 秒的渐变过渡，景物随之响应：下雪时桥面、车顶与河谷按表面朝向慢慢积起有厚度的雪——朝上的面沿法线隆起成一层蓬松雪帽（车顶能看到雪层高出屋面、边缘圆融），侧壁几乎不积，车厢内部不积雪；雨/冰雹时桥面浮现反光的积水并有雨点涟漪一圈圈荡开，地面转湿暗，冰雹过后桥面留冰粒；落叶时飘下的是带叶柄的枫叶形叶片（绿/红渐变），桥面也铺上同形落叶；雾天谷地漫起雾团、远景隐去。
- 车厢模式下天气会贴上窗玻璃：雨天细密的水痕带着水珠头缓缓下滑，雪天细小雪花斑点附着在窗外，玻璃纹理按真实比例平铺。
- 光线随太阳走：清晨与黄昏天色泛橙，白天日光明亮、投下整座列车与拱桥的影子（日/月共用一盏主光平滑交接，不会出现双重影），车窗与路灯熄灭，入夜月亮升起、星空浮现。车厢灯傍晚亮起、深夜熄灭、清晨再亮、白天熄灭；桥灯与村灯天黑亮起、天亮熄灭，村庄各片区的窗灯错峰明灭；车头灯夜里与恶劣天气自动点亮。
- 深夜晴空的河谷两岸会浮起点点萤火；深夜晴朗时偶有低概率极光，绿色光帘在天际缓缓波动（可用参数强制开启，见下）。
- 右上角「环境音」按钮开启或关闭声音，默认关闭；开启后有车轮压过轨缝的咔嗒声、夜风底噪，雨声、冰雹敲击声、雪天风声随天气渐入渐出，进隧道时声音带上回声，停站时站台铃与发车提示音先后响起，鸣笛时汽笛更清楚。
- 停站与隧道都发生在区域边界：到站时减速对位、车门滑开、候车人影上车、站台铃响，停留片刻后关门发车提速；穿隧道时洞内暖灯与车灯交织、外界天光压暗、回声浮现，出洞瞬间天光豁然恢复，同时两岸已换成新地形。
- 右上角「拍照」按钮隐藏全部界面元素，把当前画面导出为 `dusk-express.png`，伴随快门闪光与提示。
- 列车始终向前：桥墩、枕木、桥灯与两岸的村庄、树影、山脊不断向后掠过并循环回收，车轮与连杆随之转动，烟囱持续吐烟，车窗暖光微微闪烁。
- 地形库与区域接力：世界按约 36 秒一段划分为区域，每段从地形库（河谷 / 平原 / 丘陵 / 山岭 / 森林 / 湖泊 / 海滩 / 海洋）中按邻接表随机抽取下一段——海洋只接海滩、海滩接平原或海洋、山岭只接丘陵或森林等，保证「海洋 → 海滩 → 草原」式的合理过渡，且避免连续重复最近两种地形。进入新区域时左上角浮出「驶入 · 地名」提示，远景山脊在数秒内渐变成新地形的轮廓与色调，海浪 / 阵风 / 萤火等环境音与粒子也随地形渐入渐出。
- 过渡库：每段边界随机绑定一种过渡方式——转弯（世界整体弯出弧线、车身轻微侧倾，约 13 秒后回直）、穿隧道（石砌门洞与洞内暖灯，仅出现在丘陵 / 森林 / 山岭一侧）、到站停车（减速对位、开门上下客、站台铃、关门发车），另有少量开阔直行的边界；山岭边界大概率穿隧道，海岸边界大概率转弯或停站。
- 轨道库：每种地形自带轨道形态——河谷 / 山岭 / 湖泊 / 海滩 / 海洋走高架拱桥，平原 / 丘陵 / 森林走地面路堤。地面区段的地形整体抬升为台地，铁轨两侧挖出等高走廊，再沿走廊堆出一道碎石道床路堤，坡脚随地形起伏自动放坡，保证全线铁轨始终在同一高度；丘陵与森林的路肩两侧还会切出堑坡。桥与路堤的交界处立石砌桥台，桥墩、桥灯、电报杆与信号机在路堤段自动落回地面高度。地面区段的隧道顶着一座覆土草丘，门洞从丘坡两端探出。
- 区域交界的地面高度、配色与岸线在约 20 米带内逐顶点混合，水面按 8 米列逐列生成，岸线随边界推进而渐变，不会出现硬切。
- 远景机位闲置片刻后会缓缓自动环绕；一旦拖动即交还控制权。

## 沿途风景

- 铁路侧：电报杆与垂弧电线、红绿臂板信号机、一座无人小站（站台、暖灯、站牌、长椅与候车的人影、木箱，列车会在此停靠上下客）、一座石砌隧道（门洞、檐口、洞内吊灯），随列车掠过并循环回收。
- 河谷：转叶的风车、冒炊烟的屋舍、跨河拱桥与码头边点着灯的泊船、田畦、草垛、栅栏、果园、坡上的羊群、河畔芦苇；河面浮着低雾，映着车窗与村灯的竖向倒影。
- 平原：成块麦田与干草垛、栅栏线、散树、农舍与转叶风车、坡上羊群。
- 丘陵：起伏草坡、梯田条带、干砌石墙、散树与岩石、羊群与牧屋。
- 山岭：峡谷高壁、雪顶石笋群、隘口隧道门洞；风声更强、萤火绝迹。
- 森林：密植松杉与阔叶树、伐木小屋与原木堆、林间岩石。
- 湖泊：开阔湖面、木栈桥与泊船、岸边芦苇；月夜湖面铺一个更宽的月光带。
- 海滩：沙洲与草滩、漂流木、渔屋、红白灯塔（夜里旋转光束）、近岸泡沫线。
- 海洋：全幅海面、远岛、浮标与夜航船影；月光带最宽，海浪声最明显。
- 水面是活的：三重行浪在顶点着色器里起伏并实时倾斜法线，日光/月光随波面碎成粼粼高光，浪尖泛白沫；浪幅按地形分级——海洋最涌、海滩次之、湖泊微澜、河谷只起细纹，浮标与船影按同一浪面函数上下起伏并轻微摇摆。
- 天空：缓缓漂移的云（夜色紫、白天白）、从谷地升起的天灯、晴夜偶尔划过的流星、白天掠过的飞鸟；月晕轻微呼吸，日月随时刻升落。

## 说明

所有贴图均由 Canvas 程序化生成，运行时不发起任何网络请求。`?shot=1` 隐藏 HUD；`?shot=1&mode=orbit|follow|ride` 指定机位；`?warm=N` 先确定性预演 N 秒再截图；`?hour=H&weather=W&auto=0` 锁定时刻与天气（weather 取 clear/rain/snow/hail/fog/leafG/leafR）；`?event=stop|tunnel` 让列车尽快进入停站 / 隧道事件；`?region=X&next=Y&transition=curve|tunnel|stop|open` 指定首段地形、下一段地形与边界过渡方式（地形取 valley/plains/hills/mountains/forest/lake/beach/ocean）；`?track=ground|bridge` 强制全线走地面路堤 / 高架桥；`?aurora=1` 强制开启极光，便于复现同一画面。

桥身、枕木、桥灯与雨雪冰雹落叶粒子均用 InstancedMesh / Points 合批，灯光光晕与萤火用实例化广告牌一次绘制，静态景物按材质合并几何；积雪通过着色器按法线朝向注入：朝上的面既染白又沿法线微微隆起，形成有厚度的雪帽而非平面贴白，不增加网格；转弯时同一「世界弯曲」顶点着色器作用于全部世界材质与阴影深度材质——铁轨、桥面、隧道壳等长条构件沿行车方向细分后再弯曲，避免整段平移错位，灯杆、电报杆、信号机等轨旁设施与月光带、水面倒影、泡沫线同步弯折；列车保持刚性，每节车厢按中心线弧函数落到弯道上并取切线朝向，车轮始终压在轨面上，车身随弯道轻微侧倾（约 4°），车顶雪帽与车窗光晕单独处理以免重复弯曲；车厢机位的眼点随车体侧倾、视线只带四分之一侧倾（乘客头部保持大致竖直），窗外地面与地平线在转弯全程可见；全部滚动（桥墩、轨枕、灯杆、地形块、远山）统一由里程计 dist 取模推导，停站加减速也不会让桥与地面产生相对滑移；隧道始终整段落在地面路堤一侧（桥↔路堤边界时自动平移进地面区域），覆土草丘不会悬空压在高架桥上；水面按 8m 列无缝拼接，行浪相位与地块周期对齐，杜绝接缝闪烁；页面隐藏时暂停渲染循环与音频，`prefers-reduced-motion` 下关闭自动环绕与晃动。
