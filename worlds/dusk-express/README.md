# 暮行灯列 · Dusk Express

星夜的高架桥上，一列亮着暖窗的慢车驶过河谷。可以远观整列火车压过拱桥，可以伴飞在车头旁，也可以坐进车厢，透过车窗看两岸灯火与映月的河流。

## 交互

- 拖动环视，双指（或滚轮）缩放；车厢模式下拖动是转头看窗外，缩放调整视野宽窄。
- 轻点车头鸣笛：一声汽笛伴着一团蒸汽从烟囱涌出。
- 底部「远景 / 伴飞 / 车厢」三个按钮切换机位；键盘 `1` / `2` / `3` 同样可切换。
- 底部环境栏：点天气按钮在 晴朗 / 下雨 / 下雪 / 冰雹 / 雾天 / 绿叶 / 枫叶 之间手动切换；拖动时刻滑杆从早到晚拨动一天；「自动」开启后时间缓缓流转（约 4 分钟一天）、天气随机更替。手动操作会暂停自动，再点「自动」恢复。
- 天气切换有约 2.5 秒的渐变过渡，景物随之响应：下雪时桥面、车顶与河谷慢慢积雪，雨/冰雹时桥面浮现积水、地面转湿暗，冰雹过后桥面留冰粒，落叶时桥面铺上绿/红落叶，雾天谷地漫起雾团、远景隐去。
- 光线随太阳走：清晨与黄昏天色泛橙，白天日光明亮、车窗与路灯熄灭，入夜月亮升起、星空浮现。车厢灯傍晚亮起、深夜熄灭、清晨再亮、白天熄灭；桥灯与村灯天黑亮起、天亮熄灭；车头灯夜里与恶劣天气自动点亮。
- 右上角「环境音」按钮开启或关闭声音，默认关闭；开启后有车轮压过轨缝的咔嗒声、夜风底噪，鸣笛时汽笛更清楚。
- 列车始终向前：桥墩、枕木、桥灯与两岸的村庄、树影、山脊不断向后掠过并循环回收，车轮与连杆随之转动，烟囱持续吐烟，车窗暖光微微闪烁。
- 远景机位闲置片刻后会缓缓自动环绕；一旦拖动即交还控制权。

## 沿途风景

- 铁路侧：电报杆与垂弧电线、红绿臂板信号机、一座无人小站（站台、暖灯、站牌、长椅与候车的人影、木箱），随列车掠过并循环回收。
- 河谷：转叶的风车、冒炊烟的屋舍、跨河拱桥与码头边点着灯的泊船、田畦、草垛、栅栏、果园、坡上的羊群、河畔芦苇；河面浮着低雾，映着车窗与村灯的竖向倒影。
- 天空：缓缓漂移的云（夜色紫、白天白）、从谷地升起的天灯、晴夜偶尔划过的流星、白天掠过的飞鸟；月晕轻微呼吸，日月随时刻升落。

## 说明

所有贴图均由 Canvas 程序化生成，运行时不发起任何网络请求。`?shot=1` 隐藏 HUD；`?shot=1&mode=orbit|follow|ride` 指定机位；`?warm=N` 先确定性预演 N 秒再截图；`?hour=H&weather=W&auto=0` 锁定时刻与天气（weather 取 clear/rain/snow/hail/fog/leafG/leafR），便于复现同一画面。

桥身、枕木、桥灯与雨雪冰雹落叶粒子均用 InstancedMesh / Points 合批，静态景物按材质合并几何；页面隐藏时暂停渲染循环与音频，`prefers-reduced-motion` 下关闭自动环绕与晃动。
