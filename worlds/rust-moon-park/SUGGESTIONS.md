# 锈月乐园 · 优化建议

## 现状

- 体量：`index.html` 约 784 KB（three.js r160 内联），封面 224 KB。
- 画面：海边旧游乐园，摩天轮、旋转木马、过山车、售票亭与摊位、灯串、藤蔓。
- 交互：拖拽环视、双指 / 滚轮缩放、轻点地面或摩天轮有光波与加速反馈；底部「盛景 / 雨夜 / 废园」三态切换（键盘 1/2/3）；`?shot=1&mode=golden|rain|ruin`。
- 技术：程序化 Canvas 贴图（棋盘、条纹、木纹、气球、招牌、文字）、`mergeGeometries` 合并藤蔓、雨丝与水洼、`prefers-reduced-motion`。
- 定位：功能与内容量最完整的一个，也是技术上最新的一份代码（r160 基线）。

## 优点

- 三态切换给了世界「时间」，这是其它三个世界都没有的叙事手段。
- 场景密度高但组织得好：道具大量合并几何，`index.html` 仍只有 784 KB。
- 移动端处理到位：`touch-action`、`dpr` 上限、模式按钮的窄屏降级、`ResizeObserver`。

## 问题

1. 三态是「换皮」：材质和物件直接替换，缺少演化的中间过程，切换瞬间会露馅。
2. 摩天轮吊厢刚性固定，转起来像贴图，少了物理重量感。
3. 「可点击」目前只有光波，设备本身没有动作，点完不知道改变了什么。
4. 雨夜的水洼没有反射，废园的锈蚀只体现在颜色上，细节层次还有空间。
5. 390 px 下模式按钮隐藏了文字只留图标，新用户可能不知道三个图标的意思。

## 建议（按优先级）

### P0 · 三态是演化，不是换皮

- 切换时用 1.2 s 统一过渡：材质颜色 / 粗糙度插值，灯泡按 60–90 ms 间隔从近到远逐颗熄灭或点亮，藤蔓用 `scale.y` 从 0 长到 1（配合整体透明度）。
- 雨丝改用透明度淡入，而不是直接显隐；水洼在过渡后半程才出现。
- 验收：任意两态之间切换，中途没有「同时存在两套物件」的闪烁；`prefers-reduced-motion` 下退化为 200 ms 直切。

### P1 · 摩天轮有重量

- 吊厢绕挂点做 ±4° 的钟摆摆动，角速度与轮速反向耦合，到顶点时自然回正。
- 轮心加一声极轻的机械「咔哒」可选音效（首次点击后创建 `AudioContext`，默认关闭）。
- 验收：转速变化时吊厢摆动连续，不出现逐帧抖动。

### P2 · 每台设备都有动作

- 旋转木马：点击后 2 s 加速到 0.5 rad/s，运行 8 s 再缓停。
- 过山车：点击后一辆车厢沿预设曲线跑完一圈（约 6 s），可用 `CatmullRomCurve3` + 时间参数驱动。
- 售票亭：点击弹出「今日闭园」小牌子（Canvas 贴图），废园模式下再点一次可让灯串闪三下后重新熄灭。
- 验收：动作互不阻塞；同一设备重复点击不叠加计时器。

### P3 · 雨夜与废园的细节

- 水洼加简易反射：把摩天轮灯串渲染成 3–5 个加法混合的竖向光斑贴片，随水洼位置偏移，不做真正反射。
- 废园模式给金属件加锈迹：在现有 `addTint` 基础上叠加一张程序化噪声贴图（128×128），做 `roughnessMap` 或颜色乘法，成本很低。
- 手机端模式按钮在 390 px 下保留 2 字短标签（「盛景 / 雨夜 / 废园」），只隐藏英文副标题。

## 不建议做

- 不要做第四种环境（雪天 / 万圣节）。三态已经形成闭环，再加会稀释每态的完成度。
- 不要在雨夜加水体模拟或屏幕空间反射，贴片方案足够，且这个世界的 draw call 已经很满。
