# 锈月乐园 · Rust Moon Park

海边的一座旧游乐园：盛景、雨夜、废园、雪境、花季与霓虹六种环境可以随时切换。

## 交互

- 拖动环视，双指（或滚轮）缩放，轻点地面或摩天轮会有光波与加速反馈。
- 底部「盛景 / 雨夜 / 废园 / 雪境 / 花季 / 霓虹」六个按钮切换环境；键盘 `1`–`6` 也可切换。
- 雨夜会落下雨丝并积起水洼；废园会熄灯、生锈、长满藤蔓与杂草。
- 雪境会积雪、落雪并在屋顶与长椅上堆起雪层；花季会长出花丛、粉樱与飞舞的花瓣；霓虹会把摩天轮、旋转木马与拱门点亮成夜色灯管。

## 设施

摩天轮、旋转木马、过山车、咖啡杯、海盗船、旋转飞椅、跳楼机、碰碰车，以及摊位、帐篷、码头和小船。
