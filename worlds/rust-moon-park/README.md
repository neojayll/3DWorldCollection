# 锈月乐园 · Rust Moon Park

海边的一座旧游乐园：盛景、雨夜与废园三种环境可以随时切换。

## 交互

- 拖动环视，双指（或滚轮）缩放，轻点地面或摩天轮会有光波与加速反馈。
- 底部「盛景 / 雨夜 / 废园」三个按钮切换环境；键盘 `1` `2` `3` 也可切换。
- 雨夜会落下雨丝并积起水洼；废园会熄灯、生锈、长满藤蔓与杂草。

## 文件

- `index.html`：单文件自包含场景，three.js 已内联，离线可运行。
- `preview.jpg`：入口大厅封面（1600 × 1000）。
