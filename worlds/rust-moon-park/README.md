# 锈月乐园 · Rust Moon Park

海边的一座旧游乐园：盛景、雨夜、废园、雪境、花季与霓虹六种环境可以随时切换。

## 交互

- 拖动环视，双指（或滚轮）缩放，轻点地面有光波；双击（或双触）空白处回到默认视角。
- 轻点任意设施会启动它自己的动作：旋转木马转一圈、过山车跑一趟、海盗船再荡一回、飞椅与茶杯加速、跳楼机再升一次、碰碰车开快一点，摩天轮则亮灯加速。开启环境音后，每种设施被点中时还会有一声短促的机械响动。
- 底部「盛景 / 雨夜 / 废园 / 雪境 / 花季 / 霓虹」六个按钮切换环境；键盘 `1`–`6` 也可切换。
- 切换不是瞬间换材质：颜色在几秒内渐变，锈迹按顺序爬上漆面，藤蔓沿支架一点点爬升、叶片随藤尖依次展开，灯泡一颗颗熄灭；反向切换时它们会依次复原。
- 摩天轮吊厢会随转速与加速度自然摆动。
- 右上角「环境音」按钮开启或关闭声音，默认关闭；开启后六种环境各有不同的底噪（海浪、雨、风、雪、虫鸣与电流嗡响），并会随镜头位置与朝向产生远近和左右变化，设施方向也有各自的声源。
- 雨夜会落下雨丝并积起水洼，水洼里映出设施灯光的竖向倒影；废园会熄灯、生锈、长满藤蔓与杂草，漆面带有细微的锈蚀颗粒质感。
- 雪境会积雪、落雪并在屋顶与长椅上堆起雪层；花季的花丛会从广场向外陆续冒头，粉樱与花瓣同时出现；霓虹的灯管会逐根闪烁着点亮、再归于稳定，把摩天轮、旋转木马与拱门点亮成夜色灯管。

## 设施

摩天轮、旋转木马、过山车、咖啡杯、海盗船、旋转飞椅、跳楼机、碰碰车，以及摊位、帐篷、码头和小船。
