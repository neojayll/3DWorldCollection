# 暮色浮岛 · 优化建议

## 现状

- 体量：`index.html` 约 723 KB，three.js 已内联，封面 108 KB。
- 画面：黄昏低多边形浮空小岛、木屋、暖橙天光。
- 交互：拖拽旋转、滚轮 / 双指缩放，没有可点击的对象。
- 定位：整个收藏的「原点」世界，气质最稳，但信息量最低。

## 优点

- 构图干净，黄昏配色和大厅完全一致，作为首页第一个世界很合适。
- 相机与缩放的手感已经调好（含拖拽方向修复），不需要再动基础操作。

## 问题

1. 只能看，不能参与。用户点任何东西都没有反馈，容易在 10 秒内离开。
2. 木屋是画面焦点，却没有「有人住」的迹象：窗内是静态亮片，没有灯的变化。
3. 岛是悬浮的，但边缘没有任何动态（没有瀑布、落石、飞鸟），缺少「浮」的感觉。
4. 夜景只有一个状态，回访没有新鲜感。

## 建议（按优先级）

### P0 · 木屋活起来

- 点击木屋：3 盏窗户灯按 120 ms 间隔依次点亮，烟囱开始冒烟（8–12 个半透明面片，沿正弦漂移 + 淡出）。
- 再点一次熄灭。用 `Raycaster` 拾取木屋整体包围盒，不要逐面拾取。
- 验收：点击后 600 ms 内灯全亮，烟雾循环无跳变；移动端点击不误触旋转。

### P1 · 岛的边缘

- 在岛的一侧加一道细瀑布：`PlaneGeometry` + 自定义 shader（向下 UV 滚动 + 底部渐隐），落入虚空后淡出，不需要水体模拟。
- 加 6–9 只鸟：一个 `InstancedMesh` 或合并几何，沿椭圆轨道飞行并轻微上下起伏，成本可忽略。
- 验收：瀑布不穿帮、不与地形 z-fighting；鸟群不进入相机近裁剪面。

### P2 · 一座绳桥

- 从主岛连到一块 3–4 米的小浮岛，绳桥用两段悬链线（`CatmullRomCurve3` + `TubeGeometry`）。
- 小浮岛上放一盏路灯或一块石碑，作为「走过去有东西看」的目标。
- 验收：桥的弧度自然，小岛随主岛同步轻微浮动。

### P3 · 黄昏 / 星夜

- 右下角一个极轻的切换按钮（与大厅同款描边胶囊），把天空、雾色、平行光强度和窗灯在 1.5 s 内插值到夜景。
- 夜景额外加 20–30 个萤火虫（Points + 呼吸透明度）。
- 注意：新增 UI 必须适配 390 px，且 `prefers-reduced-motion` 下直接切换不插值。

## 不建议做

- 不要加水面反射、体积光或后处理。这个世界的价值是「安静」，加特效会和大厅抢注意力，也会推高移动端功耗。
- 不要引入外部模型或贴图，现有程序化风格已经很统一。
