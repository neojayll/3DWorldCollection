# 崖灯守屋 · Cliff Lantern

黄昏的海崖上，守塔人的小屋与灯塔。点击木门进入屋内，可在门厅、厨房、书房、卧室之间走动，最后沿旋梯登上灯室。

## 交互

- 室外：拖动环视，双指（或滚轮）缩放；点击小屋木门进入门厅。
- 室内：拖动环视，双指（或滚轮）调整视野；点击门或楼梯前往其它房间。
- 左上角面包屑与「返回」按钮逐级退出，`Esc` 同样返回上一层。
- 整座小屋、四间房与灯塔同处一个连续场景：进屋、串房间、沿旋梯登顶都是同一段运镜，不切场、不二次加载、不闪白。

## 文件

- `index.html`：单文件自包含场景，three.js 已内联，离线可运行。
- `preview.jpg`：入口大厅封面（1600 × 1000）。
