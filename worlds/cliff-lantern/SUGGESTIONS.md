# 崖灯守屋 · 后续建议

记录当前实现的取舍与可继续打磨的方向，按优先级排列。

## 现状

- 室外为海崖、灯塔、守塔人小屋与程序化草石；室内为门厅 + 厨房 / 书房 / 卧室 + 灯室。
- 房间首次进入才构建，同一时刻仅一个房间可见；切换时用黑幕遮住构建耗时。三个壁灯与蜡烛共用闪烁动画。
- 所有材质贴图由 Canvas 生成，离线可运行。

## P0 · 值得先做

1. **灯室光束联动室外**：进入灯室时让室外扫海光束加速，并给透镜加一圈动态光晕，强化「登上灯室」的回报感。
2. **房间进入动效**：每次切换房间时给相机 200–300 ms 的轻微推进（dolly-in），比纯黑幕更有「推门」的感觉。

## P1 · 提升细节

1. **可交互小物件**：壁炉/灶火可拨旺、书房台灯可点亮、卧室蜡烛可吹灭，用简单的开关状态 + 光照插值实现。
2. **窗外动态**：书房海景窗与卧室月光窗加入缓慢移动的云影或雨丝，避免「贴图窗」的静止感。
3. **门厅挂钟走时**：把钟面指针接上真实时间，与整体黄昏氛围形成对照。

## P2 · 氛围与声音

1. **环境音**：用 WebAudio 合成海浪、木屋风鸣与灯室低频嗡鸣，默认静音，提供右上角开关。
2. **壁炉粒子**：厨房灶火加少量上升火星，复用室外烟雾的 Points 实现。

## P3 · 可探索性

1. **隐藏阁楼**：门厅楼梯上方加一个可点击的小阁楼入口，放望远镜与航海日志，作为彩蛋。
2. **守塔人日记**：在书房桌面放可翻页的日志（Canvas 贴图切换），交代小岛背景。

## 不建议做

- 不要为每个房间单独加载外部贴图或模型，会破坏单文件与离线前提。
- 不要同时渲染所有房间，手机端会明显掉帧。
- 不要把房间做成完全封闭的盒子，镜头在房内时容易穿墙；保持「三面墙 + 敞开正面」的舞台式结构。
